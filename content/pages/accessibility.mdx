# Accessibility at New York Titans.

We design and build this site to be usable by as many people as possible, including people who use assistive technologies.

## Standard

We target **WCAG 2.2 Level AA**. We test the site continuously against this standard using automated tools and manual review on real devices and assistive technologies.

## What we do

- Body text contrast meets or exceeds 7:1 against background.
- Every interactive element is reachable by keyboard with a visible focus ring.
- All informative images have meaningful alt text.
- Headings form a logical hierarchy with one H1 per page.
- Forms have visible labels, helper text, and accessible error messages.
- Animations are minimal and respect `prefers-reduced-motion`.
- A skip link allows keyboard users to jump to main content.

## Tested with

- NVDA (Windows) for screen reader navigation.
- VoiceOver (iOS) for mobile screen reader navigation.
- Keyboard-only navigation across all pages and forms.
- axe-core automated accessibility scanning in our build pipeline.

## Known limitations

- Some embedded media may not have full transcripts at launch. We aim to add captions and transcripts as our content library grows.

If you find an accessibility issue we have missed, please contact us. We treat accessibility issues as bugs, not feature requests.
